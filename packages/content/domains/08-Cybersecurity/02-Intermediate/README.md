# 🟡 Intermediate Level - Offensive & Defensive Security

Learn to attack and defend systems ethically.

## 📂 What You'll Learn

| Topic | Description | Estimated Time |
|-------|-------------|----------------|
| [Web Security](./Web-Security/) | OWASP Top 10, XSS, SQL Injection, CSRF | 4-6 weeks |
| [Penetration Testing](./Penetration-Testing/) | Methodology, reconnaissance, exploitation | 4-6 weeks |

## 🎯 Learning Objectives

By the end of this level, you should be able to:
1. Identify and exploit common web vulnerabilities.
2. Perform structured penetration tests.
3. Use tools like Burp Suite, Metasploit, and Nmap.
4. Write penetration testing reports.
