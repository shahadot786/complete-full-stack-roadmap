# 🏗️ Infrastructure-as-Code (IaC)

Stop clicking buttons in the UI. Define your infrastructure in code for consistency and speed.

## 🗺️ Learning Roadmap

### 1. Provisioning with Terraform
- HCL (HashiCorp Configuration Language)
- Providers and Resources
- State Management (`terraform.tfstate`)
- Modules and Variables
- Plan, Apply, and Destroy

### 2. Configuration Management with Ansible
- Playbooks and Tasks (YAML)
- Inventory Management
- Roles and Handlers
- Idempotency

### 3. Cloud-Native IaC
- **AWS CloudFormation:** JSON/YAML templates
- **Cloud Development Kit (CDK):** Using Python/TS for infra
- **Pulumi:** Modern IaC with general-purpose languages

## 📚 Recommended Books
- **Terraform: Up & Running** by Yevgeniy Brikman
- **Ansible for DevOps** by Jeff Geerling
- **Infrastructure as Code** by Kief Morris

## 🛠️ Hands-on Projects
1. **Terraform S3 Bucket:** Deploy an S3 bucket with versioning enabled using Terraform.
2. **Ansible Web Server:** Use Ansible to install Nginx on a remote EC2 instance.
3. **Multi-tier Infra:** Use Terraform to build a VPC with public and private subnets.
