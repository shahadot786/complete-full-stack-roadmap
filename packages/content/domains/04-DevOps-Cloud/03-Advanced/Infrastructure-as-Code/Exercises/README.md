# 📝 Infrastructure as Code (IaC) - Exercises

Refine your HCL and YAML syntax.

## 🎮 Interactive Challenges
- **[HashiCorp Learn](https://developer.hashicorp.com/terraform/tutorials)** - Excellent official tutorials with built-in terminals.
- **[Ansible Galaxy](https://galaxy.ansible.com/)** - Explore and try to use existing roles created by the community.

## ⚡ Quick Tasks
1. **State Hunter:** Find where your `terraform.tfstate` file is and explain why you should never delete it manually.
2. **Variable Injection:** Modify a Terraform script to take the region name as a variable instead of hardcoding it.
3. **Dry Run:** Use `ansible-playbook --check` to see what a playbook would do without actually changing anything.
4. **Module Builder:** Take a repeating block of resource code and turn it into a reusable Terraform module.
