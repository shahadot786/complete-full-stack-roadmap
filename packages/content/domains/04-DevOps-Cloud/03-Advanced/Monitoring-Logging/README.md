# 📊 Monitoring, Logging & Observability

You can't fix what you can't see. Learn to track the health and performance of your systems.

## 🗺️ Learning Roadmap

### 1. Monitoring & Metrics
- **Prometheus:** Modern monitoring and alerting
- **Grafana:** Visualizing metrics (Dashboards)
- **Alertmanager:** Handling alerts (Slack, Email, PagerDuty)

### 2. Log Aggregation
- **ELK Stack:** Elasticsearch, Logstash, Kibana
- **EFK Stack:** Using Fluentd instead of Logstash
- **Loki:** Prometheus-inspired logging for Grafana

### 3. Distributed Tracing
- **Jaeger** / **Zipkin:** Visualizing requests across microservices
- **OpenTelemetry (OTel):** The modern standard for observability

## 📚 Recommended Books
- **Prometheus: Up & Running** by Brian Brazil
- **Observability Engineering** by Charity Majors
- **Site Reliability Engineering (SRE) Book** by Google

## 🛠️ Hands-on Projects
1. **Grafana Dashboard:** Create a dashboard that visualizes your local machine's resource usage.
2. **Prometheus Exporter:** Write a simple Python script that exports custom metrics to Prometheus.
3. **Centralized Logging:** Deploy an ELK stack using Docker Compose and ship logs from a web app.
