## 🎯 Why React Native?

| Advantage | Description |
|-----------|-------------|
| **Cross-Platform** | Single codebase for iOS and Android |
| **JavaScript/TypeScript** | Leverage existing web skills |
| **Hot Reloading** | See changes instantly during development |
| **Large Community** | Massive ecosystem and community support |
| **Native Performance** | Compiles to native code |
| **Code Sharing** | Share code with React web apps |

### Who Uses React Native?
- Facebook, Instagram, Walmart, Bloomberg, Discord, Pinterest, Shopify

## 🚀 Getting Started

### Option 1: Expo (Recommended for Beginners)

```bash
# Install Expo CLI
npx create-expo-app@latest MyApp

# Navigate to project
cd MyApp

# Start development server
npx expo start
```

### Option 2: React Native CLI

```bash
# Create new project
npx react-native init MyApp

# Navigate to project
cd MyApp

# Run on iOS
npx react-native run-ios

# Run on Android
npx react-native run-android
```

### Development Environment Setup

**Required Tools:**
- Node.js (v18+)
- Watchman (macOS)
- Xcode (for iOS development)
- Android Studio (for Android development)
- VS Code with React Native extensions
