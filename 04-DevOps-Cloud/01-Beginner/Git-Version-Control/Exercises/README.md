# 📝 Git & Version Control - Exercises

Test your branching and merging skills.

## 🎮 Interactive Challenges
- **[Learning Git Branching](https://learngitbranching.js.org/)** - An incredible visual simulator for every Git command imaginable.
- **[Githug](https://github.com/Gazler/githug)** - A Ruby gem that provides 50+ levels of Git challenges.

## ⚡ Quick Tasks
1. **Stash Master:** Start a change, stash it, switch branches, come back, and apply the stash.
2. **Cherry-pick:** Pick one specific commit from a "dev" branch and move it to "production".
3. **Bisect:** Find which commit introduced a specific text change in a large repo using `git bisect`.
