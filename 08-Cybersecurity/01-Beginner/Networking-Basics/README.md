# 🌐 Networking Basics for Security

Understanding networks is essential for security professionals.

## 🗺️ Learning Roadmap

### 1. OSI & TCP/IP Models
- 7 layers of OSI
- TCP/IP protocol stack
- Encapsulation and headers

### 2. Common Protocols
- HTTP/HTTPS, FTP, SSH, DNS
- SMTP, IMAP, POP3 for email
- DHCP, ARP, ICMP

### 3. Network Tools
- **nmap** - Port scanning
- **Wireshark** - Packet analysis
- **netcat** - Network swiss army knife
- **tcpdump** - Command-line packet capture

### 4. Network Security
- Firewalls and ACLs
- VPNs and tunneling
- Network segmentation

## 📚 Recommended Books
- **Network+ Guide to Networks** by Jill West
- **TCP/IP Illustrated** by W. Richard Stevens
- **Practical Packet Analysis** by Chris Sanders
