# 🟢 Beginner Level - Security Foundations

Build the foundation for a career in cybersecurity.

## 📂 What You'll Learn

| Topic | Description | Estimated Time |
|-------|-------------|----------------|
| [Security Fundamentals](./Security-Fundamentals/) | CIA triad, threats, security concepts | 3-4 weeks |
| [Networking Basics](./Networking-Basics/) | TCP/IP, protocols, network security | 3-4 weeks |

## 🎯 Learning Objectives

By the end of this level, you should be able to:
1. Explain the CIA triad and common security principles.
2. Understand common attack types (phishing, malware, DDoS).
3. Use basic networking tools (nmap, Wireshark).
4. Configure basic firewall rules.
